MEDIA ENGINE

What the YouTube connection is for

Systems Unpacked Media Engine is an operator-controlled content production and publishing system for educational technical content about software architecture, cloud infrastructure, AI systems, reliability, and engineering. When the operator explicitly authorizes publishing, the application uses Google OAuth authorization only for the YouTube upload capability needed to upload approved Systems Unpacked videos to the operator-authorized YouTube channel.

The current publishing workflow is deliberately restricted to private YouTube uploads. Publishing actions are separately authorized; connecting the application does not automatically publish content.

Responsible use: Systems Unpacked Media Engine does not use Google APIs to create, upload, distribute, facilitate, or otherwise support non-consensual intimate imagery, including AI-generated non-consensual intimate imagery (AI NCII).

For details about Google/YouTube data handling, see the Privacy Policy.
