# Systems Unpacked Web

A web platform for exploring and understanding complex systems.

## Project Structure

```
systems-unpacked-web/
├── index.html
├── privacy/
│   └── index.html
├── terms/
│   └── index.html
├── assets/
│   └── styles.css
└── README.md
```

## Getting Started

This is a static website project. To run locally:

1. Open `index.html` in your web browser, or
2. Serve with a local HTTP server:
   ```bash
   python -m http.server 8000
   # or
   npx http-server
   ```

## Pages

- **Home** (`index.html`) - Main landing page
- **Privacy Policy** (`privacy/index.html`) - Privacy policy
- **Terms of Service** (`terms/index.html`) - Terms and conditions
